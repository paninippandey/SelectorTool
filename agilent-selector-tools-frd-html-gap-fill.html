Overview

Intro

This document covers the Agilent selector-tool experience for users who need to find a compatible column, consumable, accessory, kit, or equivalent Agilent part. The experience supports hub browsing, category filtering, guided selector questions, recommendation results, product comparison, cross-reference search, and selector entry points from product or category contexts.

C01 · Card

Selector Tool Card

Visual placeholderC01 Selector Tool CardAdd approved crop from selector hub.
PurposeRepresent one available selector or finder tool in a hub, category-filtered tab, product page, or related-tools module.
Content displayedTool family label, tool name, one-line starting-point description, and directional link affordance.
User behaviorUser selects the card to open the corresponding selector page.
System behaviorSystem routes to the selected selector and updates breadcrumb context with the active tool name.
Authoring requirementsConfigure tool label, name, starting-point description, display category, count inclusion, route, sort order, and availability.
Data dependenciesSelector tool inventory, category taxonomy, count model, and route map.
Responsive behaviorTool cards reflow from multi-column desktop layout to narrower stacked layouts as viewport width decreases.
Analytics requirementsTrack tool-card launch with tool name, category, source module, active tab, and page context.
Accessibility requirementsEntire card requires a descriptive accessible name, keyboard activation, and visible focus state.
State behaviorSupports default, hover/focus, active tab-filtered visibility, and unavailable/hidden states where a tool is not active.

State behaviorSupports empty, typed below threshold, lookup enabled, searching, found, no exact match, equivalent found, and continue-enabled states.

Accessibility requirementsProduct actions require product-specific labels; compare checkbox, spec toggle, and commerce actions require keyboard support and visible focus.
State behaviorSupports top recommendation, compare selected, full specifications expanded/collapsed, direct-match result, and cart/quote submitted states.
